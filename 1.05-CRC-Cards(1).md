# 1.05 Sketch the Classes with CRC Cards

**Project:** Smart Parking Lot

Each card shows the **Class**, its one **Responsibility**, the things it **does or knows**, and its **Collaborators**.
🔌 marks the point where a new type or rule slots in.

**Changes from the project guide's classes:**
- Removed `Attendant` (optional in the proposal, unused in the prototype).
- Added `CompatibilityPolicy` and `FacilitySettings` so matching rules and limits are not hard-coded.
- Added `ReservationService`, `ParkingService` and `PaymentService` to coordinate the workflows.

---

## Users

### User (abstract)
**Responsibility:** Hold the account details every role shares.

| Does / knows | Collaborators |
|---|---|
| Knows id, name, contact | |
| Signs in | |

🔌 **New user role:** add a subclass of `User`. Nothing else changes.

### Driver (extends User)
**Responsibility:** Start the actions a person who parks can take.

| Does / knows | Collaborators |
|---|---|
| Knows their vehicles | Vehicle |
| Requests a reservation | ReservationService |
| Checks in on arrival | ReservationService, ParkingService |
| Pays for a stay | PaymentService |

### Administrator (extends User)
**Responsibility:** Review and correct exceptions.

| Does / knows | Collaborators |
|---|---|
| Reviews and resolves incidents | Incident |
| Changes a space's status manually | ParkingSpace |
| Edits facility settings | FacilitySettings |

## Facility

### Vehicle
**Responsibility:** Describe one vehicle (plate and type).

| Does / knows | Collaborators |
|---|---|
| Knows plate and vehicle type | |
| Knows its driver | Driver |

🔌 **New vehicle type (e.g. Truck):** add the type, one row in `CompatibilityPolicy`, one price in `Rate`.

### ParkingLot
**Responsibility:** Own the spaces and answer "what is free for this vehicle?"

| Does / knows | Collaborators |
|---|---|
| Knows its levels and spaces | ParkingSpace |
| Lists available compatible spaces | ParkingSpace, CompatibilityPolicy |
| Assigns a free compatible space | ParkingSpace, CompatibilityPolicy |

### ParkingSpace
**Responsibility:** Track one space's type and status, and prevent double assignment.

| Does / knows | Collaborators |
|---|---|
| Knows id, level, type, status (Available, Reserved, Occupied, Out of service) | |
| Reserves, occupies and releases itself | Reservation, ParkingSession |

🔌 **New space type (e.g. Loading Bay):** add the type and one entry in `CompatibilityPolicy`.
🔌 **New space status:** add the status value and decide if it counts as available.

### CompatibilityPolicy
**Responsibility:** Decide whether a vehicle type fits a space type.

| Does / knows | Collaborators |
|---|---|
| Answers `isCompatible(vehicleType, spaceType)` from a rule table | Vehicle, ParkingSpace |

Current rules: Standard → Standard, Accessible. Motorcycle → Motorcycle, Standard. EV → EV. Accessible → Accessible.

🔌 **New vehicle/space rule:** add a row to the table. No other class changes.

## Booking and stay

### Reservation
**Responsibility:** Hold one space for one driver for a time window.

| Does / knows | Collaborators |
|---|---|
| Knows reference, driver, vehicle, space, arrival time, expiry, status (Reserved, Checked in, Completed, Cancelled, Expired) | |
| Cancels itself | ParkingSpace |
| Turns into a session on check-in | ParkingSession |

🔌 **New reservation rule (e.g. deposit, booking limit):** add the check in `ReservationService`.

### ParkingSession
**Responsibility:** Record one stay from entry to exit.

| Does / knows | Collaborators |
|---|---|
| Knows vehicle, space, start time, end time, status | Vehicle, ParkingSpace |
| Reports its duration | |
| Asks `Rate` for the fee | Rate |
| Closes itself | ParkingSpace |

🔌 **New session rule (e.g. overstay penalty):** add the check in `ParkingService`.

| Does / knows | Collaborators |
|---|---|
| Knows id, type, details, space, status, resolution | |

🔌 **New incident type (e.g. wrong-space parking):** add the type. The class that detects it creates the `Incident`.

## Coordinators

### ReservationService
**Responsibility:** Run the reservation workflow from request to expiry.

| Does / knows | Collaborators |
|---|---|
| Checks the space is free and compatible, then creates the reservation | ParkingSpace, CompatibilityPolicy, Reservation, FacilitySettings |
| Cancels and expires reservations | Reservation, ParkingSpace |
| Opens an incident when verification fails or a reservation expires | Incident |

### ParkingService
**Responsibility:** Run the parking workflow from entry to exit.

| Does / knows | Collaborators |
|---|---|
| Starts a session on entry and occupies the space | ParkingSession, ParkingSpace, ParkingLot |
| Sends the time-limit reminder | ParkingSession, FacilitySettings |
| On exit, requests payment, closes the session and releases the space | PaymentService, ParkingSession, ParkingSpace |

🔌 **New entry/exit source (sensor, gate):** send its events to this class.

### PaymentService
**Responsibility:** Turn a finished session into a recorded payment.

| Does / knows | Collaborators |
|---|---|
| Computes the amount due | ParkingSession, Rate |
| Creates the payment and records its result | Payment |
| On failure, keeps the session open and opens an incident | ParkingSession, Incident |
