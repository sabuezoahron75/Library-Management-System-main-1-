# CRC Cards

This document defines the Class-Responsibility-Collaborator (CRC) cards for the **Smart Parking Lot System**[cite: 1]. Each class is assigned a single clear job, along with marked extension points (`[Extension Point]`) indicating where new types or business rules can be slotted in without rewriting core logic.

---

## User Account & Role Classes

### User
**Owner:** Clark Stephen B. Gueta
| Responsibilities | Collaborators |
| :--- | :--- |
| Store core user profile credentials and authentication state (ID, name, email, role) | `Driver`, `Attendant`, `Administrator` |
| Validate login credentials and manage basic account access | — |
| **[Extension Point]** Support adding new user role subtypes without modifying base profile fields | — |

### Driver
**Owner:** Clark Stephen B. Gueta
| Responsibilities | Collaborators |
| :--- | :--- |
| Manage driver-specific profile data and registered vehicles | `User`, `Vehicle` |
| Initiate space reservations and view active parking sessions or receipts | `ReservationService`, `ParkingSession`, `Payment` |

### Attendant
**Owner:** Clark Stephen B. Gueta
| Responsibilities | Collaborators |
| :--- | :--- |
| Assist with manual vehicle check-in/check-out and verify on-site parking availability | `User`, `ParkingService` |
| Report and log on-site lot issues or violations | `Incident` |

### Administrator
**Owner:** Simvile Devanni Z. Ginga
| Responsibilities | Collaborators |
| :--- | :--- |
| Configure parking lot layout, space capacities, and pricing rules | `User`, `ParkingLot`, `Rate` |

## Parking Infrastructure Classes

### ParkingLot
**Owner:** Simvile Devanni Z. Ginga
| Responsibilities | Collaborators |
| :--- | :--- |

| Track overall lot capacity and query real-time available spaces | `ParkingSpace`, `ParkingService` |
| **[Extension Point]** Support multiple lot zones, floors, or facility branches | — |

### ParkingSpace

| **[Extension Point]** Slot in new space types (e.g., motorcycle, VIP, electric charging) | — |

## Reservation & Session Classes

### Reservation
**Owner:** Justine Mark N. Joven
| Responsibilities | Collaborators |
| :--- | :--- |
| Hold booking details including reserved space, vehicle, scheduled time window, and booking status | `Driver`, `Vehicle`, `ParkingSpace` |
| Track reservation lifecycle states (`Pending`, `Confirmed`, `Cancelled`, `Expired`) | `ReservationService` |

### ReservationService
**Owner:** Justine Mark N. Joven
| Responsibilities | Collaborators |
| :--- | :--- |
| Create, modify, validate, and cancel space reservations while preventing double-booking | `Reservation`, `ParkingLot`, `ParkingSpace` |
| **[Extension Point]** Plug in new booking rules (e.g., grace period limits, advance booking windows, cancellation fees) | — |

### ParkingSession
**Owner:** Jiro G. Lique
| Responsibilities | Collaborators |
| :--- | :--- |
| Record active parking stay details (entry timestamp, exit timestamp, assigned space, vehicle) | `Vehicle`, `ParkingSpace` |
| Calculate total elapsed parking duration upon checkout | `ParkingService`, `Rate` |

### Rate
**Owner:** Jiro G. Lique
| Responsibilities | Collaborators |
| :--- | :--- |
| Define pricing structures (hourly, flat-rate, or vehicle-type tariffs) | `ParkingSession`, `Vehicle` |
| Compute the total parking fee based on session duration and applicable tariff | `ParkingService` |
| **[Extension Point]** Slot in new pricing rules (e.g., peak-hour surge, weekend rates, PWD/senior discounts) | — |
